
# Quberyn Launcher

A premium Minecraft Java Edition Launcher for Android.

Quberyn Launcher is an open-source Android project designed to deliver a smooth, modern, and customizable Minecraft Java Edition experience.

## Features
- Modern and premium user interface
- Minecraft Java version management
- Fabric, Forge and NeoForge support
- Mod and resource pack management
- Shader support
- Performance optimization
- Customizable launcher experience

## Project Status
Currently in development.

## Vision
To create a powerful, feature-rich Minecraft Java Edition launcher for Android.
